# LaVision Monorepo

Production-ready initial architecture for LaVision immersive AI platform.

## Apps
- `apps/web`: Next.js App Router frontend with Three.js immersive module.
- `apps/server`: Express + MongoDB API backend.
- `packages/shared`: shared types and constants.

## Quick start
1. Copy `.env.example` files.
2. Install dependencies per app.
3. Start MongoDB (or Atlas) and run both services.
